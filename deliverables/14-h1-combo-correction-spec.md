# 14 — H1 组合修正与融合规格（C0-C6）

> 日期：2026-11-13 ｜ 状态：待确认后执行
> 本文件是对「596 种一级标题组合修正融合」任务的**需求重写**，绑外部客观标准 S1-S6。
> 与 R'0-R'9（01-requirement.md）互不冲突；C 系列只覆盖组合规范化层。

## 〇、问题的真实结构（数据钉死的事实）

全量 38,350 份报告，596 种 `canonical_cat` 序列组合：

| 事实 | 数据 |
|------|------|
| Top20 序列组合覆盖 | 94.7%（Top10=92.7%，Top50=97.0%，Top100=98.0%） |
| 尾部 576 种组合 | 仅覆盖 2,039 份（5.3%），其中 **95.6% 由 ch_zh 确定性通道提取** |
| 忽略顺序坍缩 | 596 → **322 个集合类**；Top2 集合类 87.8%（差在 documents vs glossary） |
| 真噪声规模 | ≈2.4%：95 份空、~35 份超长（md_h1 全提）、~780 份单节碎片（notice-only 为主） |

**推论**：596 不是 596 个待修问题，而是一个生成模型的输出空间：
`组合 = 法规模板基座 ⊕ 条件节合法子集 ⊕ 前后置节(notice/glossary/documents) ⊕ 提取噪声`。
逐一**归因**（每个组合落到生成路径），不在报告级逐一修补；修正发生在**规则层**，改完整体重提。

## 一、需求（每条绑外部锚）

### C0 可证伪性（总纲）
每份报告的最终组合必须满足二选一：(a) 落入法规模板正演语法；(b) 带证据记录的豁免。
**锚**：合法实例化集合由 `legal_chapters.json` 可计算枚举，任何人可重跑复核。

### C1 语法符合率 ≥99.5%
组合 = 模板基座(no2_2021_15/no3_2021_16/no2_2025_3/no3_2025_4) ⊕ 条件节子集(preferred/bonds 2^k) ⊕ 已登记前后置节。
**锚**：正演枚举脚本输出符合率表，逐 reg_version 分列。

### C2 金标一致率：节存在性 ≥98%，槽位对齐 ≥95%
分层抽样 ≥300 份（按年份×板块×提取方法分层），独立通道裁决。
**锚**：金标 CSV + Cohen's kappa ≥0.9；裁决记录留档。

### C3 跨度可复现 100%
规范化管线重跑输出 byte-identical（对齐 AGENTS.md E4 精神）。
**锚**：输出 sha256 前后一致；规则表版本号写入每条记录。

### C4 跨年稳定率 ≥97%
同一发行人相邻年份组合一致，或差异可由 reg_version 切换解释。
**锚**：逐发行人 diff 报告，不可解释差异逐条列名。

### C5 近失消除 ≥50%
与 Top20 组合编辑距离 ≤1 的"近失组合"数量减少 ≥50%，且 C2 金标一致率不下降（防规则过拟合）。
**锚**：前后对比表。

### C6 豁免预算 ≤0.5%
不可解释组合 ≤192 份，每条豁免必须引用原文 span（byte_start/byte_end）+ TOC 证据。
**锚**：豁免表逐条可复核。

## 二、语义分层（融合的正确姿势）

- **集合层**：canonical_template_id + slot_alignment（每节填哪个法定槽位）
- **顺序层**：front_matter / back_matter 位置差异只记录不合并（顺序本身是发行人习惯，有信息量）
- **禁止破坏性合并**：每份报告保留 delta_record（相对模板的插入/删除/换名），596 是输出统计量，不是压缩目标

## 三、执行阶段

1. **P0 归因**：596 组合逐一生成生成路径标签（模板/变体/噪声/未知），产出归因表
2. **P1 规则修复**：对噪声子类（空/碎片/超长）写版本化规则，重提，验证 C5
3. **P2 规范化落库**：canonical_template_id + slot_alignment + delta_record 入 PG，验证 C1/C3
4. **P3 金标验证**：300 份分层金标，裁决，验证 C2
5. **P4 跨年审计**：逐发行人 diff，验证 C4；剩余不可解释 → 豁免表，验证 C6
6. **P5 交付**：`deliverables/15-h1-combo-correction-report.md` + 更新 PG 表
