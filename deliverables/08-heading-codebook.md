## 〇、为什么先有这份文件

用户原方案「全量提取 → 取最高频组合 → AGENT 判断是否正确 → 入 pattern 库」隐含两个未定义前提：

1. **构造效度（construct validity）缺失**：没有可操作判据说清"一级标题"是什么，于是「AGENT 判断正确」是无标尺测量。
2. **分析单位（unit of analysis）未固定**：实证显示同一批 12,016 份语料，换一个单位，"组合数"从 **11,702 → 1,252 → 640**（差 18 倍），Chao1 未见估计从 **1,229,080 → 5,022 → 1,021**。不固定单位，任何频次结论都无意义。

> 全量数据表（12,016 份）：
> | 单位 | 唯一组合 | top1 占比 | Chao1 估计 | 未见估计 |
> |---|---|---|---|---|
> | `fp_h1` 原始 H1 文本序列 | 11,702 | 1.45% | 1,240,781.6 | 1,229,079.6 |
> | `fp_numbered` 编号型标题序列 | 1,252 | 24.74% | 6,274.16 | 5,022.16 |
> | `fp_canonical` 上游 canonical 类别序列 | 640 | 24.27% | 1,661.33 | 1,021.33 |

`fp_h1` 的 Chao1 荒谬（>100 万），因为公司名与年份是近乎无限变量——**这本身就证明原始字符串不能作分析单位**。

## 一、构造定义：什么是一级标题

### 1.1 判据（可操作，来源于 12,016 份原始字节的频次归纳，非先验规定）

一个文本行是**一级标题（L1）**当且仅当满足 **A 且 B 且非 C**：

- **A 形态**：在 MD 中为独立行，且为 `# `（H1）或 `第X章/节 标题` 形态。
- **B 结构**：满足以下任一：
  - **B1 编号型**：含 `第[中文数字|阿拉伯数字][章节部分篇]` marker，且 marker 后有非空标题名；
  - **B2 法定映射型**：无 marker，但标题文本命中 `legal_chapters.json` 对应 `reg_version` 的节名，或命中上游 `report_patterns.json` 的 15 类 canonical 变体。
- **C 排除**：命中以下任一即**不是** L1：
  - 公司名称（含「股份有限公司 / 有限公司 / 集团 / 银行 / 证券 / 保险」且无编号 marker）；
  - 报告年份名称（如 `2021年半年度报告`、`2021 年年度报告`）；
  - 纯目录/释义/备查文件标题**当其仅作扉页标记**（见 §1.3 的歧义裁定）；
  - 财报附注 / 表头 / 表格续行，实证高频反例：**`五、合并财务报表主要项目注释(续)`**（239 次）、`(续)` 变体（217 次）、`财务报表附注`（474 次）；
  - 正文交叉引用（如 `详见"第十章 财务报告"中的…`），实证 **10,650 份（88.6%）** 含此类噪声。

### 1.2 正例（真实 verbatim）

```
# 第一章  公司简介                    <- B1，marker=第一章，注意两个空格
# 第十章  财务报告                    <- B1
# 第一节 重要提示、目录和释义          <- B1（法定写法用「节」）
# 重要提示                            <- B2（canonical: notice）
# 备查文件目录                        <- B2（canonical: documents）
```

### 1.3 歧义裁定（必须显式，否则标注员/AGENT 必然不一致）

| 情形 | 裁定 | 理由 |
|---|---|---|
| 「章」vs「节」 | **等价**，marker_type 单独记字段 | `legal_chapters.json` 用「节」，平安银行等实际用「章」；实证编号标题名 Top12 与法定节名高度吻合 |
| 前置六个 H1（公司名 / 年份 / 重要提示 / 目 录 / 备查文件目录 / 释 义） | 是**扉页标记**，计入 `front_matter`，**不进 L1 组合** | 000001_2021_2.md 原始字节第 1–31 行；法定第一节「重要提示、目录和释义」在实报中被拆成 4 个独立 H1 |
| 一个法定节被拆成多个实际章（如「公司简介」+「会计数据和财务指标」） | 记 `split_of: <法定节号>`，不判缺失 | 平安银行实证；此前 `_matches_split()` 想解决但无可反驳证据 |
| 无编号且无 canonical 命中的 H1 | 记 `UNRESOLVED`，进 `evidence`，**不进统计分母** | M2 |
| 纯文本无 H1 的报告 | `NO_H1_PLAINTEXT`，判 `EXTRACTION_FAILURE` | 实证 174 份（1.4%） |

### 1.4 与 E1 的关系

L1 组合只用于判定「结构是否可提取」。**「章节是否必披」由 `reg_version → legal_chapters.json` 决定，与 L1 频次无关**。二者不得混为一谈：高频 ≠ 法定，低频 ≠ 违规。

## 二、分析单位（固定并版本化）

- **主单位**：`fp_canonical` = 上游 `extract_heading_signature()` 产出的 canonical 类别序列的 SHA-256 前 16 位。
- **辅单位**：`fp_numbered`（编号型标题序列）用于检验 canonical 映射的归并是否过度。
- **禁止**：以 `fp_h1`（原始 H1 文本序列）作频次统计单位（已被 Chao1 证伪）。
- **版本**：`unit_scheme = heading-unit-v1`，变更须走 05 C3 MINOR/MAJOR 并重跑全部 E。

## 三、标注流程（pilot → α → gold set）

1. **Pilot**：按 `year × period × source` 分层（上游 F-013，每层 ~5%）抽 200 份，双盲标注 L1 边界。
2. **一致性**：算 **Krippendorff's α**（序数/名义按字段选）；**α < 0.8 必须回头改本 codebook，不得调模型或调 AGENT**。
3. **Adjudication**：分歧由第三人仲裁，结论写回 codebook 的歧义裁定表。
4. **Gold set**：冻结 200 份，**与积累集严格隔离**，只用于验收，永不参与 pattern 归纳。
5. **边界**：α / κ **仅作标注过程质控**（04 §2-F），**不得作正确性标准**（01 §2.3 明确排除）。

> 这一节是 06 提案完全缺失的部分：06 只说「AGENT 不能当裁判」，没给出裁判如何被构造出来。

## 四、裁判四层（不得压缩成一层）

| 层 | 身份 | 职责 | 可否单独定案 |
|---|---|---|---|
| L-应然 | 法规原文 verbatim（文号 + 施行日 + 原文 sha256）→ `legal_chapters.json` | 定义「应有哪些节」 | ✅ 定义应然，但不描述实然 |
| L-实然1 | 上游 canonical 签名 + `DIVERGENT_THRESHOLD=0.3` | 独立观测的类别序列 | ❌ |
| L-实然2 | MD 原始字节 `verbatim_span` + byte offset + sha256 | 可回放证据 | ❌ 但可证伪上两层 |
| L-仲裁 | AGENT / 人工 | 仅处理分歧 | ❌ 不得产出事实 |

**M2 硬约束**：每条 L1 记录必须满足 `md_bytes[start:end].decode('utf-8') == verbatim`。本次实证 **1,926/1,926 条回放通过（0 失败）**，该检查应进 CI 属性测试。

## 五、失败分类学（实证频次，12,016 份）

| 类型 | 份数 | 占比 | 处置 |
|---|---|---|---|
| `HAS_CROSSREF_NOISE` 正文含「第X章」交叉引用 | 10,650 | 88.6% | 行首锚定 + 引号/上下文排除；不得用全文正则 |
| `ORDINAL_NOT_CONTIGUOUS` 编号不连续 | 2,137 | 17.8% | 记 `front_matter_offset` / `has_gap`，不直接判缺失 |
| `CORE_SECTION_MISSING` canonical 核心节缺失 | 1,247 | 10.4% | 先查 L1 是否通过；未通过归 `EXTRACTION_FAILURE` |
| `NO_NUMBERED_HEADING` 无任何编号标题 | 331 | 2.8% | 转 B2 法定映射路径 |
| `NO_H1_PLAINTEXT` 纯文本无 H1 | 174 | 1.4% | `EXTRACTION_FAILURE`，不进分母 |

**结构异常层**（60 份降级胜者，`selection_rule ∈ {backup_l1,l2,l3}`）：`n_h1` 均值 **76.5** vs 正常 **16.7**（4.6 倍）；32 份编号标题数为 20（正常为 10）；一份 `n_h1=505`；5 份 `n_h1=0`。**这 60 份必须整体单列 `EXTRACTION_FAILURE`**。

## 六、停止判据（不新造 k / ε）

- 主判据：上游 **S-3 单调收敛** `monotonic_check=pass`（`proof-2018-final.json` 实测 M0=2030→M1=0）。
- 覆盖上界：**Chao1 bias-corrected + bootstrap 95% CI**。本次 canonical 单位 `S_obs=640, f1=384, f2=71, Chao1=1661.33, unseen≈1021.33`。
- **实证结论：未饱和**。饱和曲线末段仍在涨（11,015 份→557 种；12,016 份→640 种，边际 +83），bootstrap 区间 [465, 501] 低于实际观测 640，说明曲线形态受语料排序影响，**不能据此宣称饱和**。
- 分层抽样验收沿用上游 F-013（每层 ~5%、覆盖率 100%、人工 pass ≥95%）。

> **对上游已冻结裁决的挑战**：`02-technical-solution.md` 断言「`patterns` 只是 Top-5 种子，`extract_heading_signature` 只用完整 15 类 canonical 变体，无需补 357 条」。实测 canonical 变体 **57 个 / 15 类**，H1 文本命中率 **78.4%**（80 份 smoke）；未命中 21.6% 主要是 `目录`(69)、年份报告名、公司名、审计报告——**多数为扉页噪声而非结构标题**，故上游裁决在"结构标题"范围内仍成立，但**必须配合 codebook 的 C 排除规则**才能成立；单靠 canonical 映射不足以判 L1。

## 七、禁止项

- 不以频次、AGENT 判断、模糊匹配阈值作正确性裁判。
- 不输出「全量合规率」作验收（01 §五.3）。

- 不读取 01 §四 未授权源（源 HTML / trash / `sina_bulletin.db` / `/backup`）。
- 不重复实现上游已有能力（铁律 4）：canonical 映射、`is_toc` / `is_heading`、`jaccard_distance`、`slot_key` 一律只读复用。
