## 零、根因审计（v1.1 新增，本次最重要的一节）

在按 v1.0 落地前，对已有 8,433 份 PDF 提取结果做了审计，发现 4 个问题。其中前 3 个是**验证体系本身的缺陷**，不是提取精度问题。

### 0.1 发现一：目录页对齐率 100% 是循环论证，不是外部锚点

| 项 | 内容 |
|----|------|
| v1.0 声称 | "目录对齐率 99.9%，外部锚点达标" |
| 实测 | 7,852 份样本中，`toc ⊆ headings`（归一化后完全包含）= **7,852 / 7,852 = 100.0%**，toc 独有项 = 0 |
| 对齐率 | 平均 1.0000，中位数 1.0000，<0.5 占比 0% —— 完美得可疑 |
| 根因 | `h1_pdf_core.py::_enrich()` 里，`headings` 与 `toc_headings` 来自**同一个 `joined` 行集合**，用同一个 `SEC_FULL_PAT` 筛选，只是 toc 多加了 `page in toc_pages` 的条件。目录页标题是提取标题的子集，等于用结果验证结果 |
| 处置 | **降级为内部一致性检查**，从验收标准中移除。不得再表述为"外部锚点" |

> 教训：一个指标如果 100% 通过，第一反应应该是查它是否自证，而不是庆祝。

### 0.2 发现二：年代（era）版本化分支实际从未生效

| 项 | 内容 |
|----|------|
| 设计 | 按 era 分支 4 套法定章节集（new/old × annual/semi） |
| 实测 | `new_annual` 8,296 / 8,433 = 98.4%；`old_*` 仅 37 份；`CANON_NEW_ANNUAL == CANON_NEW_SEMI` 完全相等 |
| 交叉验证 | era=new_annual 的记录里，period=2（半年报）有 4,612 份 —— 半年报被判成"年报" |
| 根因 | era 是靠"哪套标题集命中最多"**从内容反推**，而两套新准则集合内容相同，必然平手并取字典第一个键 |
| 处置 | 改为用**外部元数据** `report_year` + `period` 直接分支，不从内容猜。本语料 report_year 全部为 2021–2024，统一适用 2021 修订准则 |

### 0.3 发现三：法定章节集分母写错，把合格结果误判为不合格

| 项 | 内容 |
|----|------|
| 代码 | `CANON_NEW_ANNUAL` 共 **11 项**，含"备查文件目录" |
| 法规 | 证监会公告〔2021〕15号《年度报告的内容与格式（2021修订）》第二章正文为 **10 节**，"备查文件目录"不是编号节（同上交所投资者教育材料、中证投服《读懂上市公司年度报告》PPT10） |
| 影响 | 分母多 1 → 平均符合率被系统性压低 |
| 实测 | 旧分母 11 项：均值 **0.8681**，≥0.9 仅 58.3%；法规分母 10 节：均值 **0.9535**，≥0.9 达 **96.9%**，≥0.8 达 98.9% |
| 处置 | 以法规原文十节为唯一基准 |

### 0.4 发现四：第一节存在系统性别名，严格匹配会误杀

| 项 | 内容 |
|----|------|
| 实测 | 第一节写法分布：P2「重要提示、目录和释义」2,393 /「释义」2,024；P4「重要提示、目录和释义」2,380 /「释义」1,136。「释义」共 3,160 份（38.7%） |
| 影响 | 严格十节匹配把「释义」判为第一节缺失 → 缺失率 41.2%，几乎全部来自别名 |
| 修正 | 第一节允许别名集合（释义 / 重要提示、目录和释义 / 重要提示及目录 / 重要提示和释义） |
| 实测 | P2 均值 0.9485 → **0.9946**；P4 均值 0.9598 → **0.9929**；≥0.9 占比 98.4–98.6% |

### 0.5 指标性质重分类

| 指标 | v1.0 定位 | v1.1 定位 | 理由 |
|------|----------|----------|------|
| 目录页对齐率 | 外部锚点 | **内部一致性检查（不作验收）** | 与结果同源，循环论证 |
| 法定章节集符合率 | 外部标准 | **一级外部锚点（重写）** | 法规原文独立于文档，但须修正分母与别名 |
| 跨管线一致性 MD↔PDF | 未列 | **二级外部锚点** | MD 由转换器生成、PDF 由字体指纹生成，是两条独立生成链 |
| 同期横截面众数 | 未列 | **三级参考（非真值）** | 是共识结构，不是法定真值；用于发现离群，不用于判定对错 |
| 模板库覆盖率 | 内生指标 | **仅作诊断** | 自己归纳的模板验证自己 |
| 人工金标准 P/R + Kappa | 外部标准 | **一级外部锚点（待标注）** | 唯一独立于全部管线的人判断据 |

## 一、顶尖专家会采取的做法

### 1.1 从"信息提取"转向"结构识别"

**当前做法：** 从 MD/PDF 中提取一级标题  
**专家做法：** 识别文档的法定结构，一级标题只是结构的一个投影

**关键区别：**
- 信息提取是"找到什么"，结构识别是"理解什么"
- 信息提取关注准确率，结构识别关注**可靠性边界**
- 信息提取用内生指标（模板覆盖率），结构识别用**独立于生成链的锚点**（法规原文、独立管线、人工金标准）

> ⚠️ v1.0 此处把"目录页"列为外部锚点是错的，见 0.1。

### 1.2 先审计验收标准，再审计结果

专家不会先问"准确率多少"，而会先问"**这个准确率是谁判的、和我的提取过程独立吗**"。
本次审计证明：一个 100% 通过的指标恰恰是最该怀疑的指标。

### 1.3 多通道融合，不是单通道验证

```
置信度 = f(MD通道, PDF字体指纹, 法规符合率, 跨管线一致性, 横截面共识)
```
删掉了 v1.0 里的「目录页」和「模板库」——前者同源，后者内生。

不是"MD 或 PDF 哪个准"，而是"两者一致时置信度高，不一致时触发降级或人工复核"。

### 1.4 不确定性量化，不是点估计

- Bootstrap 1000 次给出 95% CI，而不是单点 96.6%
- 按 period / report_year / strategy / 版式分层报告，不看总体一个数字
- 明确标注**哪些结论没有独立真值**（本语料 301 份金标准尚未人工标注）

### 1.5 故障模式树，不是只看成功率

对每一份不通过的结果给出：根因分类 + 可修复路径 + 降级策略，而不是只报"修复率 79.3%"。

## 二、原始数据、工具、方法

### 2.1 未经加工的原始数据

| 数据源 | 内容 | 独立性 |
|--------|------|--------|
| **证监会法规原文** | 公告〔2021〕15号 / 16号，正文十节 | ★★★ 完全独立于语料 |
| **人工金标准底稿** | `stage1b_worksheet.csv`，301 份三源并排 | ★★★ 独立于全部管线（待标注） |
| MD 原文 | PDF→MD 转换器产出 | ★★ 独立生成链，但同源 PDF |
| PDF 原始文件 | 字体、字号、坐标、书签、目录点线 | ★★ 物理层 |
| PG 元数据 | `report_year` / `period` / `stock_code` | ★★★ 来自巨潮公告元数据，非内容推断 |
| 模板库 / 目录页 | 归纳产物 | ☆ 内生，仅诊断 |

### 2.2 法规原文（外部基准，已核实）

**年报**：证监会公告〔2021〕15号《公开发行证券的公司信息披露内容与格式准则第2号——年度报告的内容与格式（2021年修订）》第二章  
**半年报**：证监会公告〔2021〕16号《…第3号——半年度报告的内容与格式（2021年修订）》第二章  
两者 2021 修订后正文同为十节：

```
第一节 重要提示、目录和释义    第六节 重要事项
第二节 公司简介和主要财务指标  第七节 股份变动及股东情况
第三节 管理层讨论与分析        第八节 优先股相关情况
第四节 公司治理                第九节 债券相关情况
第五节 环境和社会责任          第十节 财务报告
```

> 旧准则（2021 前）章节不同，但本语料 report_year 全为 2021–2024，**不需要旧准则分支**。
> v1.0 花力气做的四套 era 分支是过度设计。

### 2.3 具体工具

| 工具 | 用途 | 选择理由 |
|------|------|---------|
| PyMuPDF | PDF 字体指纹 / 坐标 | 0.5–1.6s/份，可区分 14–18pt 标题与 10.4–11pt 正文 |
| psycopg2 | PG 读写 | 已有链路 |
| PostgreSQL JSONB | 半结构化结果 | 支持数组与证据字段 |
| Bootstrap（numpy） | 置信区间 | 无需分布假设 |
| rustfs (S3) | PDF 存储 | 已积累 5,764 份 |

### 2.4 专业方法：带证据的融合决策

```python
def fuse(slot):
    legal = legal_compliance_rate(pdf_or_md_headings, LEGAL_10, first_aliases)
    cross = cross_pipeline_agreement(md_headings, pdf_headings)   # 双向覆盖率
    modal = cross_section_consensus(year, period, headings)        # 离群检测，非真值

    if md_complete and legal >= 0.9:
        return md_headings, source='md', conf=0.95
    if not md_complete and pdf_available and legal >= 0.9:
        return pdf_headings, source='pdf_replace', conf=0.90
    if not md_complete and pdf_available and legal < 0.9:
        return pdf_headings, source='pdf_low_conf', conf=0.70, needs_review=True
    if not md_complete and not pdf_available:
        return md_headings, source='unrepairable', conf=0.50      # 标记，不冒充结果
    ...
```

每条结果落库时**同时写入证据字段**：`legal_rate` / `cross_agreement` / `consensus_deviation` / `failure_mode`，使任何一条结论都可回溯。

## 三、外部客观标准（v1.1 重写）

### 3.1 法定章节集符合率（一级外部锚点）

```
符合率 = |提取标题 ∩ 法规十节（含第一节别名）| / 10
```
- 基准来自法规原文，不来自任何一份报告、也不来自模板库
- 按 `period` 分支（年报/半年报），年份由外部元数据决定
- **目标 ≥ 95%**；实测修正后均值 0.993，≥0.9 占 98.5%

### 3.2 跨管线一致性（二级外部锚点）

```
MD→PDF 覆盖 = |MD 标题能在 PDF 找到| / |MD 标题|
PDF→MD 覆盖 = |PDF 标题能在 MD 找到| / |PDF 标题|
```
- MD 由转换器生成，PDF 由字体指纹生成，**两条独立生成链**
- 实测 8,331 份：MD→PDF 均值 0.8232（中位 0.9091），PDF→MD 均值 0.8354（中位 1.0000），≥0.8 占 90.4%
- 按 strategy 分层：numbering 0.826 / bookmark 0.467 / font_fallback 0.730 → **bookmark 策略需降级**
- 目标：numbering 通道 ≥ 0.80，且明确报告低于 0.5 的 8.7% 为待复核

### 3.3 同期横截面共识（三级参考，不是真值）

按 `(report_year, period)` 分组，取 ≥80% 频率的标题众数集，计算每份的偏离度。
- 实测：8 组，完全一致序列占比 37.7%–67.3%，众数集大小 8，平均众数覆盖 0.77–0.79
- **只用来发现离群（如把正文行误当标题），不用来判定对错**——多数公司写"释义"不代表法规要求写"释义"

### 3.4 人工金标准（一级外部锚点，尚未完成）

`stage1b_worksheet.csv` 301 份三源并排底稿，需双人独立标注，Kappa ≥ 0.8 后计算 P/R/F1（目标 P≥95% R≥95%）。
**当前状态：底稿已生成，标注未完成 → 这是一个必须如实声明的未闭环项。**

### 3.5 明确不用的指标

| 指标 | 不用原因 |
|------|---------|
| 目录页对齐率 | 循环论证（0.1） |
| 模板库覆盖率 | 内生自证，仅作诊断 |
| 纯度 purity | 用 `CANON_UNION` 算的，分母同样含"备查文件目录"，随 0.3 一并修正 |

## 四、用外部标准重写需求

### 4.1 原始需求（内生指标）

> 提取 34,044 份年报/半年报的一级标题，模板覆盖率 ≥ 93%

### 4.2 重写后的需求

> 对 36,899 份报告输出**可回溯的**一级标题结果，每条包含：
>
> 1. **结果**：标题列表（标准化形态）
> 2. **来源标记**：md / pdf_replace / pdf_low_conf / unrepairable
> 3. **置信度**：由法定符合率 + 跨管线一致性共同决定
> 4. **证据**：`legal_rate` / `cross_agreement` / `consensus_deviation` / `strategy`
> 5. **失败模式**：不通过时给出根因分类与修复路径，不以"修复率"掩盖
> 6. **不确定性**：关键指标给 95% CI（Bootstrap 1000 次），按 period/year/strategy 分层
> 7. **诚实声明**：明确写出哪些指标尚无独立真值（金标准未标注）

### 4.3 验收标准（v1.1）

| 指标 | 目标 | 实测/状态 | 验证方法 |
|------|------|----------|---------|
| 法定章节集符合率 | ≥ 95% | **0.993（修正后）** | 法规十节，独立 |
| 跨管线一致性（numbering） | ≥ 0.80 | **0.826** | MD↔PDF 双向覆盖 |
| 置信区间 | 必须给出 | 待阶段2 | Bootstrap 1000 |
| 失败案例可归因 | 100% | 待阶段3 | 故障模式树 |
| 金标准 P/R + Kappa | P≥95% R≥95% Kappa≥0.8 | **未闭环** | 双人标注（待办） |
| 目录页对齐率 | ~~≥97%~~ | **已废除** | 循环论证 |
